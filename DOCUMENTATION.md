## Démarche
 
J'ai travaillé section par section. J'ai commencé par écrire le HTML de chaque section avant de passer au CSS. Par exemple, j'ai d'abord fait le HTML de la 1er section, puis son CSS, et ainsi de suite. Cette méthode m'a bien convenu car elle m'a permis de me concentrer sur une section à la fois.

## Choix techniques
Pour les choix techniques j'ai utiliser les donnés de figma. Pour les catres du section programmation et artices, j'ai utiliser les données similaires.  J'ai aussi fait la même chose pour la section (hoarire et témoignages) et (le footer et la nav bar)

## Défis rencontrés
 
- **Aligner les boutons sur la même ligne** : Au début, mes boutons dans le hero et dans le formulaire n'étaient pas alignier horizontalement. J'ai résolu ce problème en ajoutant display: flex sur le conteneur des boutons.
- **Les tags sur les cartes** : J'avais de la difficulté à positionner les tags (ex: "Jour 1") dans le coin supérieur gauche des cartes. J'ai finalement résolu ce problème en utilisant position: relative sur la carte et position: absolute avec top: 0; left: 0 sur le tag.
- **Les dimensions** : J'avais de la difficulté avec certaines dimensions qui n'étaient pas exactement comme le Figma. J'ai ajusté les valeurs de width, height et padding pour le faire resembler comme le figma.


## Utilisation de l'IA
J'ai utilisé l'IA Claude, je lui ai essentiellement demandé de vérifier si mon code était bien structuré pour m'assuré que je suis sur la bonne voie. J'ai fait ça pour chaque section. Pour le prompt j'ai dit : "Pouvez-vous vérifier si mon code est bien structuré et me pointer les erreurs ?"
